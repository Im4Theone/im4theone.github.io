About

One discipline, not two.

I don't separate how something looks from how it works. Whether I'm laying out an interface in Figma, wiring a Firebase backend, or writing a Fabric mod, the same question drives the decision: does this feel obvious to the person using it.

Most of my work sits across the web stack — HTML, CSS, and JavaScript on the front end, Python, Java, and C# underneath — plus a genuine soft spot for game tooling, built from years of shipping Minecraft mods and server plugins for real communities.

Design and code, together

Interfaces are drafted before they're built, so the engineering never has to fight the design.

Simple over clever

The best system is one the next person can understand in five minutes, not fifty.

Small tools, real impact

Some of my most-used work is a plugin a few hundred people rely on every day, not a resume line.
